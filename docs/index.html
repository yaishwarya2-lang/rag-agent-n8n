What I built

Two workflows share one knowledge base. The first loads a document from Google Drive, splits it into chunks, embeds each chunk and stores it in Pinecone. The second is a chat agent with short-term memory that searches Pinecone before it replies, so answers come from the source material.

IngestionDrive → chunks → embeddings → Pinecone
RetrievalAgent calls the vector store as a tool

Decisions I made

Same embedding model on both sides. Documents and questions use Gemini embeddings, so similarity search compares like with like.
